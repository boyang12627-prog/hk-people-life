# 故事主軸提案（草案）：時代變了，人分了岔

狀態：**設計提案，未實作。** 配合 PR #8（`PRIMARY_TERM_SPEC.md`）。不推翻 1984–86、1988、1996 現有內容，只替它們加一條把玩家由三歲拉到十六歲的主線。

## 0. 前提

這是人生模擬，但需要一條**引人入勝的主軸**。主軸的引擎定為：

- **時代變遷造成的價值落差**：父母那一代求生存、求安穩、想移民留後路；主角在 80 年代末到 90 年代長大，想法漸漸不同。
- **同輩分岔**：升中派位、轉校、上下午校、移民，令阿傑和主角走上不同的路。
- **真正兩難**：每個大抉擇兩邊都有代價，玩家不知道該選哪一邊。沒有「好選項」。

情感核心不變：**怨、誤會、愛與後悔，以及多年後重新理解一個人。** 規模是一個家、一棟屋邨，不寫罪案和狗血。

**共用規則（三案都適用）：**

1. 每個兩難事件最多兩個主要選項，兩邊各付一個**看得見的代價**（一個人的失望、一次錯過、一件物件不見），代價在下一段或下一年由別人說出口，不由系統評分。
2. 代價寫成記憶卡（`memoryTypeId` 新），沿用 `EVENT_GATES`、`selectByPriority`、`missed` 規則；不加數值顯示。
3. 1997 年 6 月（主角十六歲）是終點：新增一頁結局場面，接在 1996 之後。
4. 時代事件只經電視、大人說話、物件出現：1984 聯合聲明、1987–89 移民潮、1989 六四（只寫電視開著、大人不說話）、1991–92 移民高峰、1995 BNO／居英權、1997 回歸。

## 方案一：「走定留」——家庭移民之爭（中心張力：留 vs 走）

**一句話：** 爸爸一直加班，原來是在為全家移民加拿大儲錢、等批文；這個家要不要走，最後落在十五歲的你身上。

**中心戲劇問題：** 這一家人，九七之前會不會走？你想不想走？

**秘密／承諾：** 1986 公園的「下次啦」。爸爸其實把週末拿去做第二份工、跑移民顧問。抽屜裡有一個牛皮紙信封（1988 簽卷時第一次看見一角），信封上寫著「多倫多」。玩家要到 1990 年代才知道裡面是什麼。

**幕結構：**

| 年 | 轉折 |
|---|---|
| 1984 | 聯合聲明。爸爸：「最要緊是一家人安穩。」（現有）——全劇第一句台詞即是主題。 |
| 1985–86 | 爸爸晚歸、「下次啦」（現有）。表面是失約，暗裡是為走儲錢。 |
| 1988 學期 | 簽卷時看見信封（新物件）。同事移民（現有）。成績表：爸爸「下學期唔使咁夜」。 |
| 1990–92 | 移民高峰。家裡第一次正面談「走」。嫲嫲說不走。阿傑家先走。 |
| 1996 | 批文到了。爸爸問你意見——他第一次問你。 |
| 1997 | 結局：機場、或屋邨、或分開兩地。 |

**兩難例子：**

- **1988 學期**：週六爸爸難得在家，問你要不要跟他去「見個朋友」（移民顧問）。**去**：你知道了信封的秘密一角，但錯過中秋平台，阿傑那年不再等你。**不去**：你和阿傑玩燈籠，爸爸一個人去，秘密晚幾年才揭開，而且由媽媽說出口，你會怨他瞞你。
- **1991**：嫲嫲說「我唔走，我喺度死都唔走」。媽媽要你幫忙勸。**勸**：嫲嫲那晚沒有喝你盛的湯，之後一年對你冷淡。**不勸**：媽媽說「你同你爸一樣，乜都唔講」，母子之間多一道冰。
- **1994**：你升中考得好，派到一間好的英中。爸爸說：「入咗都要走，唔使諗。」**爭取留下讀**：你讀到中三，有了自己的朋友圈，走的時候更痛。**接受**：你在學校一直不交朋友，「反正要走」，1996 才發現沒有人記得你。
- **1996**：批文到。**走**：你保住一家在一起，但留下嫲嫲（她不肯走）。**留**：爸爸十年加班白做，他第一次發脾氣，但嫲嫲最後一年有你在。

> 爸爸（1996）：「我做咗十年，就係為呢張紙。」
> 你：「你有冇問過我想唔想走？」
> 爸爸：（脫鞋，好耐）「……你細個，我問咗你都唔識答。」

**結局變奏：**

1. **一家走，嫲嫲留**：1997 年 6 月在多倫多看電視直播回歸，電話打回香港，嫲嫲說湯煲好了。
2. **一家留**：回歸夜屋邨平台放煙花，爸爸第一次星期日不返工，陪你去公園——那個「下次」終於有日子。
3. **分開**：爸媽走，你留港跟嫲嫲讀完中學（太空人家庭倒轉）。機場一幕，爸爸說「寫完就得」。

**接駁現有內容：** 爸爸線五拍全部保留，只是「原因」由「替人留到最後」加深為「儲錢、等批文」。`heardWhy` 條件不變，只多一層。1988「有個同事移民了」直接成伏筆。

**風險：** 移民題材容易變成時代說教；1996 以後要新寫兩頁（批文、結局）；「爸爸一切都是為家」可能太煽情，要讓他的固執也有錯。

## 方案二：「同一條路，兩個人」——阿傑與你的分岔（中心張力：友情 vs 前途）

**一句話：** 平台上抱紅球的阿傑，是你最早的朋友；派位、上下午校、他家的困境把你們一年一年推開，到 1997 你們再見，才知道當年誰欠誰。

**中心戲劇問題：** 你和阿傑，最後還是不是朋友？當年那件事，到底是誰的錯？

**秘密／承諾：** 1986「今次唔係搶」之後，你們約定「升中要讀同一間」。1993 派位，只有一個人遵守了。另一個秘密：阿傑爸爸失業／他要出來做事，他從沒說過。

**幕結構：**

| 年 | 轉折 |
|---|---|
| 1984 | 對阿傑無事；伏筆是父母「讀好書先有出路」。 |
| 1985–86 | 紅球、「你琴日冇落嚟」、「今次唔係搶」（現有）。約定升中同校（新句）。 |
| 1988 學期 | 你下午校、他上午校（spec D3）。見面要靠你週末落平台。媽媽開始說「唔好成日同佢玩」。 |
| 1990–93 | 你補習、他看檔。1993 升中派位：關鍵分岔。 |
| 1996 | 你在英中中四，他在做工；街上遇見，認不認他。 |
| 1997 | 結局：回歸夜平台，他有沒有來。 |

**兩難例子：**

- **1988 學期 段 5**：測驗二前一個星期六，阿傑在平台等你，說「我屋企有啲事」。**落平台**：你知道他爸爸開始沒有返工，但測驗戰鬥少一輪溫書，成績表媽媽簽，媽媽不出聲。**溫書**：成績好，爸爸簽名多一句；阿傑那年聖誕不再約你，你到 1996 才知道他那天想說什麼。
- **1990**：媽媽禁你去阿傑家（「佢屋企亂」）。**偷偷去**：你見到他家真實的樣子，但被發現，媽媽哭，你第一次覺得她勢利又覺得自己錯。**聽話**：媽媽安心，阿傑問你「你媽唔鍾意我？」你答不出。
- **1993 派位**：你可以填好學校，或填阿傑那間（約定）。**填好學校**：前途、爸媽的笑臉；違約。**填約定那間**：爸爸那晚不和你說話，十五歲的路窄了；但阿傑那年中途輟學，你守了約，他沒能守。
- **1996**：街上阿傑在搬貨，你和同學一起。**上前叫他**：同學眼神怪，你在學校被笑；**裝作不見**：他看見你裝作不見。

> 阿傑（1996）：「你唔使扮唔識我嘅。」
> 你：「我冇……」
> 阿傑：「我細個等過你㗎，你知唔知？」

**結局變奏：**

1. **重新理解**：回歸夜他來平台，帶著那個紅球（洩了氣），兩個人坐石凳，誰也不道歉。
2. **錯過**：他沒有來，嫲嫲說他前個月搬了，留下一句「話佢下次搵你」——「下次」由爸爸傳到阿傑。
3. **反轉的怨**：你守了約、他沒有；1997 他說「我冇得揀，你有」，你才明白當年怨錯了人。

**接駁現有內容：** `ARC_AH_KIT_FRIENDSHIP`、`MEM_RED_BALL`、`MEM_KIT_WAIT`、`MEM_FRIEND_AGAIN` 全部成為主線記憶；spec 已有阿傑 `withdraw` 世界規則、段 2 中秋等你，直接變成主線第一個代價。

**風險：** 爸爸線變成副線；阿傑家困境要拿捏，不能寫成貧窮奇觀；「偷偷去」等選項要防止變成教孩子騙父母。

## 方案三：「你唔明我哋嗰代」——兩代之間（中心張力：家庭 vs 自己）

**一句話：** 爸媽要你讀數數、讀英中、做實際事；你想畫畫。每一次你遷就或反抗，都在家裡留下一道誤會，到 1997 你終於知道他們年輕時也想過另一條路。

**中心戲劇問題：** 你會不會成為爸媽想你成為的人？而他們，當年又放棄了什麼？

**秘密／承諾：** 嫲嫲的鐵盒：爸爸年輕時的畫（他 1960 年代從內地來，本來想學畫，因生計放棄）。1986「畫畫還是數數」爸爸那句「多學數數，實際點」（現有）是傷口，不是冷漠。嫲嫲答應過爸爸不說。

**幕結構：**

| 年 | 轉折 |
|---|---|
| 1984 | 「一家人安穩」——安穩高於一切的價值觀定下。 |
| 1985–86 | 畫畫/數數（現有 `MEM_FIRST_INTEREST`）；爸爸「實際點」。 |
| 1988 學期 | 早上嫲嫲在家（spec）：嫲嫲看你畫，說「你似你爸細個」——第一次漏口風。 |
| 1990–93 | 六四電視那晚家裡沉默；升中選科、補習 vs 畫畫班。 |
| 1996 | 會考前，你要選理科還是設計。 |
| 1997 | 結局：嫲嫲去世或病重，鐵盒打開。 |

**兩難例子：**

- **1988 學期**：早上時段：**陪嫲嫲看電視**（她開始講爸爸細個，鐵盒伏筆）vs **做功課溫默書**（默書好，媽媽簽手冊多一句「乖」）。前者默書錯字，媽媽說「嫲嫲寵壞你」；後者嫲嫲的湯涼了兩次，鐵盒的事要遲兩年才知道。
- **1989**：你畫了電視上看到的畫面帶回家。**給爸爸看**：他把畫收起，第一次對你大聲：「唔好理呢啲」，你怨他；**藏起**：家裡平靜，但你學會不跟他說真話。
- **1993**：畫畫比賽和升中補習同一個星期六。**比賽**：得獎，爸爸沒來，成績差一級派不到好學校。**補習**：派到好學校，那張比賽表格被你摺起放進抽屜，到 1996 還在。
- **1996**：選科。**設計**：爸爸三個月不和你說話，媽媽兩面難做；**理科**：家裡安穩，你不再畫。

> 嫲嫲（1988 早上）：「你畫嘢個樣，同你阿爸細個一模一樣。」
> 你：「爸爸識畫畫㗎？」
> 嫲嫲：（停一停）「……湯好喇，飲湯先。」

**結局變奏：**

1. **和解**：鐵盒打開，爸爸看你的畫，說「比我畫得好」——一生唯一一句稱讚。
2. **遲來的理解**：你選了理科，1997 才看見那些畫，明白他當年為什麼說「實際點」，但已沒有機會問他。
3. **各自安穩**：你選了設計，爸爸不看鐵盒，只把你的畫擺在電視旁邊，一句話都沒說。

**接駁現有內容：** `MEM_FIRST_INTEREST`、`ART_PROGRESS`、`SKL_03`、嫲嫲的湯（`MEM_GRAND_DAY`）、爸爸線。spec 的早上 `ACT_TV`/`ACT_HOMEWORK` 直接變成主線兩難。

**風險：** 「父親原來也是藝術家」較常見，要寫得克制；嫲嫲病重接近煽情邊界；時代因素比方案一、二弱，要靠六四、選科、經濟轉型撐。

## 4. 建議：方案一為骨，吸收方案二的阿傑線

**選方案一「走定留」，並把方案二的阿傑分岔編成它的第二條線。** 理由：

1. **最貼時代**：1984 聯合聲明 → 1997 回歸本身就是一條倒數計時，「走定留」是那一代香港家庭真實、無對錯的兩難，最符合用家要的「時代差異＋艱難取捨」。
2. **最少推翻**：爸爸線五拍已經是現有作品最完整的一條，「替人留到最後」→「儲錢等批文」只是加深原因；1988「有個同事移民了」本身就是伏筆。
3. **天然兩邊代價**：走＝保住家庭、失去嫲嫲和朋友；留＝陪伴嫲嫲、辜負爸爸十年。玩家真的不知道選哪邊。
4. **阿傑線補人情**：阿傑家先移民（或反過來：你家要走，他家走不了），把「友情 vs 前途」嵌進同一個問題，不需另開故事。結局可組合（一家走/留 × 阿傑來/不來）。
5. 方案三的鐵盒可留作 1990 年代嫲嫲的副線素材，不入主軸。

**風險控制：** 爸爸也要有錯（瞞你、不問你），媽媽要有自己的立場（她其實想留），嫲嫲是「留」的一方，不是背景。
