# 角色聲音（V3.4）

這份文件分兩層。

- **旁白和動作**（`narration`、`action`）一律用簡潔的書面中文。`src/game/wording.ts` 的對照表在這一層強制執行，審計會失敗。
- **對白**（`dialogue`，即 `say(...)`、`speaker:` 回想句，以及旁白裡用「」引住的說話）按說話的人寫。對照表在這一層不強制。`dialogueWarnings` 只會列出可能不自然的句子，寫在 [VOICE_WARNINGS.md](VOICE_WARNINGS.md)，給作者再看一次。

## 語域

| 語域 | 意思 | 例子 |
|---|---|---|
| `formal` | 書面中文，老師對全班說話那種 | 「不用怕，進去和其他小朋友玩。」 |
| `narrative` | 書面語法，夾香港用詞和節奏（一陣、好累、今日、返工、波） | 「等一等。媽媽今日好累。」 |
| `colloquial` | 照廣東話說出來的樣子（唔、咗、嘅、㗎、喎） | 「個波係我先攞到㗎！」 |

每個說話的人都有預設語域（`DEFAULT_REGISTER`，在 `src/game/scene.ts`）。個別句子可以用 `say(speaker, text, register)` 另外標。
**不要每句都寫成口語。** 口語留給書面語讀起來會假的那幾句。一頁裡有一兩句地道的就夠。

---

## 媽媽（預設 `narrative`）

- **語域：** 書面語法，夾香港用詞：一陣、今日、好累、波、多謝。不用很重的語氣詞。
- **節奏：** 短句、命令句多：「到了就進去。」「不要自己跑出去。」問句也短：「今日去了平台？」
- **不會說的話：** 不說「我擔心你」「我愛你」。不跟孩子解釋大人的事。不抱怨爸爸。
- **潛台詞：** 擔心都化成家務和吩咐。「今晚早點睡」就是「明天很重要」。累的時候先坐下，後脫鞋。

## 爸爸（預設 `narrative`）

- **語域：** 書面語法，最少的字。用「返工」不用「上班去了」。
- **節奏：** 一句不超過十個字。說事實，不說感受：「我返工了。」「下次吧。」「寫完就好。」
- **不會說的話：** 不說辛苦，不說為什麼晚，不給日期（所以「下次」沒有日子）。不道歉。
- **潛台詞：** 「最要緊是一家人安穩」他只說一次，之後只做不說。脫鞋脫得很慢，就是他一整天的話。孩子要問，他才會說一句原因（1986「等公司請到人」、1988「有個同事移民了」）。

## 嫲嫲（預設 `colloquial`）

- **語域：** 地道廣東話，老人家的用字：以前、邊有、掣、㗎。
- **節奏：** 慢，常常由「以前」開始。一句講完會停一停。
- **不會說的話：** 不訴苦，不說自己悶。不催孩子。
- **潛台詞：** 湯就是她的話。湯涼了再熱一次，就是在等你。

## 阿傑（預設 `colloquial`）

- **語域：** 小孩的廣東話：個波、今次、唔係、你嚟唔嚟、啦。
- **節奏：** 很短，很直，常有感嘆號。一句不超過十四個字。
- **不會說的話：** 不直接說對不起，不說「我想和你做朋友」。
- **潛台詞：** 「你琴日冇落嚟」其實是「我等過你」。「今次唔係搶」就是和好。
- **README 鎖定的兩句：** 翌日「你琴日冇落嚟。」、下一年「你去年冇落嚟。」。V3.4 起是廣東話，意思和回收窗口都不變；旁白轉述時仍寫書面語（「他說你昨天沒有下來」）。

## 阿姨（預設 `colloquial`）

- **語域：** 街市檔口的廣東話，快、熟絡：呢個、唔使錢、高咗、喎、嚟㗎。
- **節奏：** 一開口就像已經認識你。問句後面不等答案。
- **不會說的話：** 不直接講錢和人情，不說「不用還」的道理，只說「街坊嚟㗎」。
- **潛台詞：** 多塞一條菜就是她的好意。她記得的是「那個孩子」，不一定記得名字。

## 老師（預設 `formal`）

- **語域：** 書面中文，課室裡對很多孩子說話。
- **節奏：** 清楚、慢，一句一個指示：「你跟著我讀兩個字就行。」「還有五分鐘。」
- **不會說的話：** 不用俚語，不在孩子面前評論家長。
- **潛台詞：** 她同時看著很多孩子。記得你的畫，就是很大的稱讚。

## 改寫時

1. 先看說話的人是誰、幾歲、和孩子有多親、這一刻是什麼心情。
2. 意思不變，只改說法。不要加新的資料。
3. 改完跑 `npm run audit:content`。旁白有粵語字會失敗；對白只會出 `VOICE WARNING`。
4. 重新產生 [VOICE_WARNINGS.md](VOICE_WARNINGS.md)：`node --import ./scripts/register-ts-ext.mjs --experimental-strip-types scripts/voice-report.ts`
