# 人生・香港 Art Bible V1.0

狀態：1985 直切已放進 `public/art/1985/`。臉以 `cast.jpg` 為準。其他年份的空房間不是標準，沒有重畫。

倉庫裡原先沒有場景檔。工作區裡有六張空房間，是大人的視線，沒有人。那些不是這份的標準，1985 直切不沿用。

## 一句

打開一本舊相簿，裡面的人開始動。平時是生活插畫。有壓力時，同一個地方變擠。多年後，舊物在現在的畫面上短暫疊一下。

本作品不以香港地標作為香港感的主要來源。禁止把霓虹、電車、維港、太平山、唐樓天際線畫成主體。香港感來自日常物件的密度、空間有多窄、人和人有多近。

## 畫面語言

兩個畫師必須畫出同一套，所以下面用規則，不用形容詞。

比例：

- 四歲，頭身長比 1:4.5。頭約佔身高兩成二。不是 1:2 的大頭。
- 五歲 1:5。七歲 1:5.5。十五歲 1:6.5。
- 大人若必須全身，1:7。1985 的畫面裡，大人從胸口或腰裁掉。

鏡頭：

- 高度 95 公分，四歲的眼睛。
- 相當於 40mm。不用 24mm 廣角，不用 85mm 廣告虛化。
- 近處的手、球、門檻清楚。三公尺外只留形狀，不寫招牌上的字。

線：

- 沒有純黑勾邊。形體靠顏色和陰影分開。
- 若有線，只用暖棕 `#5c4a3a`，透明度不超過三成，只在頭髮和衣褶，不把整個人圈起來。

光：

- 只有一個主光。1985 是門裡的日光，偏紙色，不是正午的白。
- 沒有輪廓光，沒有三盞燈。陰影軟，邊緣看得見。

顏色和顆粒：

- 沒有比琥珀 `#c9843a` 更鮮的顏色。紅球是舊塑膠，偏暗，不高於這顆琥珀。
- 大面積是紙 `#f3ead7`、墨 `#241c14`、雨灰和屋邨綠 `#35665d`。
- 全圖一層細鉛筆顆粒。看得到，但不能數點。不是厚油畫，不是照片。

臉：

- 眼睛約佔臉寬五分之一。有眼白，瞳孔小。
- 不畫圓腮紅，不畫星星高光。嘴多半合著。
- 手指短，五根分開。重心在兩腳。不插腰，不飛髮，不對鏡頭露齒笑。

材質隨年紀換，不是同一張圖換濾鏡：

| 年 | 必須是這些材料 |
|---|---|
| 1984 | 木、塑膠、舊電視、布、暖燈 |
| 1985 | 雨水、濕地、校舍油漆、塑膠凳 |
| 1986 | 水泥、晾著的衣服、鐵閘、螢光燈 |
| 1988 | 紙、擦膠屑、原子筆、木書桌 |
| 1996 | 較清楚的玻璃、街燈、制服、書包。仍是同一個人的臉 |

底色仍是程式裡的墨、紙、琥珀、屋邨綠。年代不另做一套主題。

## 人物

臉以 `public/art/1985/cast.jpg` 為準。後續圖不得另起一張臉。

四歲主角，男女同一張臉、同一種膚色（暖米褐）、同一雙眼睛。女孩是剛過耳的短髮，男孩是耳上的短髮。衣服是洗舊的棉衫、深色短褲、白襪、膠拖鞋。

媽媽三十歲上下。髮在腦後，臉比老師圓，眼睛往下看孩子。淺色上衣，深色長褲，帆布鞋。累，不漂亮。1984 是家居服和拖鞋。1985 手還牽著。1986 兩隻手各一袋餸。

老師四十歲上下。臉較長，髮夾住，淺色罩衫。招手。不是壞人。

阿傑和主角同年，稍高一點。短髮，舊橫間衫。站在一顆有蹭痕的暗紅色塑膠球旁邊。

1. 幼稚園門口，95 公分高
2. 主角（男、女各一張，五官相同）
3. 媽媽
4. 老師
5. 阿傑
6. 紅球
7. 戰鬥時同一扇門變擠，不換地方，不出現怪
8. 戰鬥介面仍是精神力、氣力、壓力、目標
9. 進去之後的結果
10. 1996 只疊一小塊舊畫面，然後還是現在
11. 1986 仍是這扇門、這張臉，孩子略高，媽媽提著兩袋

做完才畫 1984 飯桌、1986 走廊、1988 試卷、1996 街。1988 的卷子以後要自己變成場地：紙變髒、字變密、時鐘變大。現在不畫。

## 記憶和物件

記憶不是回到過去的一幕。1996 的畫面留著，疊上小手、紅球、門或那隻不走的錶，然後消失。

塑膠錶普通到有點醜。可以有舊膠帶、不走的針、花痕。不是寶物。

## 字和介面
