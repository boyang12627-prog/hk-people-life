# 正式小學一學期規格（草案）：1988 小二上學期

狀態：**設計規格，未實作。** 本學期是 [LIFE_SPINE.md](LIFE_SPINE.md) 第四階段「入小學」（1987–89）的可玩部分；主軸、兩難規則、戰鬥規則以 LIFE_SPINE 為準。 這份文件鎖定正式小學的形狀，之後才量產內容。不開 V4.0 擴充，不做 1989 及以後。現行 1988 `prototype-slice`（筆 → 測驗 → 簽卷）是原型，這份規格會取代它，但保留它已證明可行的部分。

標記：**〔現有〕** 引擎已有，直接用；**〔新〕** 需要新引擎工作；**〔內容〕** 只是寫資料。

## 1. 範圍與設計目標

**範圍：** 1988 年 9 月至 1989 年 1 月，小二上學期，一個學期。主角七歲。只做這一個學期，做完先過真人試玩。

**時代背景（只經電視、大人對話、物件出現，不上歷史課）：**

- **上下午校：** 主角讀**下午校**（12:45–17:45）。早上在家：嫲嫲、電視、做功課。放學天已近黑。這是和 1985–86「下午」最大的分別：自由時間由下午搬到**早上和星期六日**。
- **手冊：** 每日抄功課、家長簽名。手冊是全學期的「記事簿」介面，見第 5 節。
- **默書、測驗、考試：** 默書每週一次；測驗（中英數）十月、十二月各一輪；上學期考試一月初。
- **成績表：** 一月尾派，家長簽名。是學期的終點。
- **節日：** 中秋（1988 年 9 月 25 日，星期日）、聖誕、元旦。
- **1988 背景：** 漢城奧運（9–10 月，電視轉播）；移民潮開始（爸爸「有個同事移民了」已在原型）；越南船民（新聞一句，大人轉台）；政改白皮書年初已出、不再提。最多每月一句，不解釋。

**設計目標（按優先）：**

0. 埋下主軸三粒種子：信封（`MEM_ENVELOPE`）、阿傑分岔、嫲嫲「我唔走」（`MEM_GRAND_STAY`）。兩難兩邊都要有代價（LIFE_SPINE 第 2 節）。
1. 玩家記得自己這學期**做過什麼、錯過什麼**，而且知道是自己的選擇。
2. 多年後（1996）回看，因為這學期而說法不同。
3. 一學期在試玩中約 **12–15 分鐘** 玩完（全局 25–30 分鐘內）。
4. 不加新數值顯示；不回復「記下了」數值列表（`playtest-audit.test.ts` 已守住）。

## 2. 時間流

### 2.1 單位

| 層 | 單位 | 數量 | 玩家控制 |
|---|---|---|---|
| 學期 | 1988 小二上 | 1 | 無 |
| 段 | 約三週一段 | 6 段 | 無（固定） |
| 週 | 一週一頁「週頁」（手冊那一頁） | 18 週，玩家只**落地**其中約 9 週 | 無 |
| 時段 | 早上（上學前）／星期六／星期日 | 每段 3 個 AP | **有：每段揀 3 個時段做什麼** |

- 「一學期 3 AP」（README）在這裡解讀為**每段 3 AP**，全學期 18 AP。見第 8 節決定 D1。
- 上學時段（12:45–17:45）**不由玩家揀**。學校裡的事是固定或結果事件（第 3 節），在週頁裡發生。
- 沒有落地的週，週頁只出一行（手冊的抄寫），按一下就過。這是「時間在走」的感覺，不是內容。

### 2.2 與現有系統的對應

- `YearCalendar`（`content.ts`）加 **〔新〕** `"primary-term"`。1988 的 `YearDef` 改用它；`prototype-slice` 退役。審計要擋住第二個 `primary-term` 年份（README「不要把 1988 抄去 1989」）。
- `State.apLeft`、`State.spent` **〔現有〕** 沿用，但每段重設。需要 **〔新〕** `State.term: { week: number; segment: number }`（`schemaVersion` 升 4，`validateState` 要接受舊存檔並丟掉 1988 進度）。
- 時段活動沿用 `ACTIVITIES` **〔現有〕**：`ACT_MARKET`、`ACT_DRAW`、`ACT_REST`、`ACT_ESTATE`、`ACT_PLAY`，另加 **〔內容〕** `ACT_HOMEWORK`（做功課／溫默書）和 `ACT_TV`（早上看電視，嫲嫲在）。標籤按時段改（`activityLabel(id, year, slot)` 已收 `slot` 參數）。
- 誰在哪裡：`resolveWorldAt` / `worldTick` 目前只認 1985/86、`Day = "sat" | "sun"`。**〔新〕** 加 `Day` 值 `"morning"`，加 `WORLD_1988` 表；`worldTick` 每段結束跑一次（現在只在 `sat` 跑）。
- Phase：沿用 `year → activities → event → result → year-end` **〔現有〕**，中間加 **〔新〕** `"week"` phase（週頁）。`reducer` 加 action `nextWeek`。
- `lifeSim.ts` 的 `PLAN` 只有每年兩格；**〔新〕** 1988 改成每段三格，`simulateLife` 步數上限（220/260）要放寬。

### 2.3 一段的流程

```
段開頭週頁（手冊）→ 揀時段 1 → 該時段事件 → 揀時段 2 → … → 揀時段 3
→ 本段固定學校事件 → 結果事件（如有）→ 下一段
```

## 3. 事件節奏

### 3.1 三類事件

| 類 | 定義 | 引擎 |
|---|---|---|
| **固定** | 每局一定出：開學、中秋、測驗、考試、成績表 | `YearDef.events` 〔現有〕 |
| **隨機** | 時段落點抽一件：街市、平台、電視、早上的家 | `buildQueue` 的 `dailies` 抽法〔現有〕，改成每段抽〔新〕 |
| **結果** | 只在掙到時出：簽卷、阿傑等你、老師留堂、嫲嫲熱湯 | `EVENT_GATES` 〔現有〕；閘門目前只讀 `memories`，要多讀 `term.segment`〔新〕 |

### 3.2 密度上限（審計要測）

- 每段：固定 ≤ 2、結果 ≤ 1、隨機 = 時段數（3，可以是 `MINI_QUIET`）。
- 每段有選項的卡 ≤ 4。全學期有選項的卡 ≤ 22。
- 戰鬥（`PRIMARY_EXAM` spec）全學期 ≤ 2 場：十二月測驗、一月考試。默書不開戰鬥，是一張卡。
- 卡片回聲沿用 `selectByPriority`／`ECHO_CAP = 2` 〔現有〕，週頁回聲上限 1。

## 4. 角色成長

### 4.1 主角（七歲）

- 數值沿用 `Primary` / `Derived` **〔現有〕**，不新增鍵。小學只讀：`STAT_MIND`（測驗）、`STAT_GRIT`（溫書耐力）、`STAT_SPEECH`（課堂答問、新同學）、`STAT_COURAGE`（舉手、問爸爸）。
- 每段時段效果上限：任一 primary +1。全學期 primary 總變化 ≤ +6，避免小學一學期蓋過三年童年。
- 性格標籤沿用 `personalityTags`；`designTendency` 照舊只記錄不改數。
- **玩家看不見數字。** 成長只在文字中出現：例如默書由「你錯了好多個字」變成「你只錯了一個」。

### 4.2 爸爸（V3.4 爸爸線，本學期兩拍）

爸爸線現在是 1984 → 1985 → 1986 → 1986 夜 → 1988 簽卷 → 1996（`dadArc`）。小學一學期**不加新選項，只加半拍（看見信封與否）**，並把簽卷拉長成兩次：

1. **段 4 簽測驗卷**（現有 `EVT_1988_DAD_SIGN`，閘門不變：`MEM_DAD_WORK` + `MEM_EXAM_PAPER`）。選項 C「為什麼這麼晚」→「有個同事移民了」，寫 `MEM_DAD_SIGN` choiceId `C`，`dadArc` 已讀。
2. **段 6 成績表** 〔內容〕：誰簽由之前決定。爸爸十點後才回 → 媽媽簽，旁白寫「媽媽簽了。爸爸那一格空著。」；簽過測驗卷且問過為什麼 → 爸爸簽，多一句。
   - 爸爸：「寫完就得。」（不變，鎖定）
   - 爸爸（問過才有）：「下學期唔使咁夜。」——仍是沒有日期的「下次」。

### 5.3 錯過的規則

1. 錯過只看記憶卡和 `missed`，不看世界狀態（V3.3 規則）。
2. 每件可錯過的事，**在錯過的下一段**最多提一次，由當時在場的人說出口；再下一次只在 1996。
3. 錯過寫成別人過了那一天：「阿傑中秋喺平台玩到好夜。」不寫「你錯過了 X」。
4. 錯過的事不補做。學期內同一件事不會再給第二次機會（1985 門口那種重來不適用於小學）。

### 5.4 不靠數值提醒玩家

「記下了」數值列表已移除，不回來。提醒用：

- **手冊** 〔新 UI〕：每段開頭的週頁就是手冊一頁，上面有你這幾週的痕跡：家長簽名是誰的筆跡、默書分數、老師的紅字。玩家翻手冊就會記得自己做過什麼。手冊不顯示 STAT。
- **物件**：擦膠、燈籠、原子筆出現在畫面（`equipment` 〔現有〕）。
- **別人的話**：嫲嫲「你今朝又冇睇電視」——提醒而不評分。
- **每頁回聲**：`ECHO_CAP` 2 句，同主題一句〔現有〕。

## 7. 驗收標準與真人試玩問題

### 7.1 自動審計（`npm run audit:content` 必須過）

1. 只有 1988 用 `primary-term`；1989 不存在。
2. 每段事件數、選項卡數、戰鬥數不超過 3.2 上限。
3. 每個結果事件在掙到之前不出現（仿現有爸爸線測試）。
4. 每個新記憶至少一個消費者（`ledger.ts` 規則）。
5. 錯過的事在下一段最多提一次。
6. 每頁回聲 ≤ 2，週頁 ≤ 1，1996 ≤ 3。
7. 結果頁不出「記下了」、不出數值名。
8. `runChildhood` 五種童年在 1988 結束時 `seen` 互不相同；1996 頁句子至少三種不同。
9. 每個主線兩難的兩個選項各寫一張有消費者的記憶卡；`MEM_ENVELOPE` 不在段 4 前出現。
10. 旁白過 `wording.ts`；對白只出 `VOICE WARNING`。

### 7.2 真人試玩（沿用 `PLAYTEST_KIT.md`，加三題）

合格：在 V3.4 八條之上，另加——

- 學期部分平均 ≤ 15 分鐘，沒有人在週頁卡住。
- 至少一半人不用提示說得出這學期兩件自己做過的具體事。
- 至少一半人說得出一件錯過的事，並知道是因為自己（例如揀了溫書沒去平台）。

訪談加問（插在第 4 題之後）：
