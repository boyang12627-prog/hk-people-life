# 人生主軸（三層結構，草案）

狀態：**設計，未實作。** 以 `STORY_SPINE.md` 方案一「走定留」為骨，併入阿傑分岔線。主角 1981 年生（1984 三歲、1996 十五歲，與現有內容一致）。

## 0. 三層

1. **主軸（固定）**：每個人生階段一件**人生大事**，綁一個當年真實的**民生議題**。玩家改變不了大事發生，只改變自己在大事裡的位置。
2. **成長抉擇（分支）**：每階段 2–3 個真兩難，兩邊都有代價；核心張力是兩代價值落差（求安穩／留後路 vs 孩子自己的想法）與同輩分岔（阿傑）。
3. **階段戰鬥（結算）**：每階段一場，沿用現有「一份 engine、多份 spec」。戰鬥是「孩子面對一件比自己大的事」，不是打人。

故事插曲（有日期）掛在三層上面，只經電視、大人說話、物件出現。

## 2. 三層怎樣互動

1. **主軸固定、位置可變。** 每階段的人生大事一定發生（上樓、北上、派位、搬屋、批文、九七）。玩家的選擇只決定：誰在場、誰說了什麼、你知道多少。不出現「選了就不搬屋」。
2. **只有兩個主軸分歧點**：1993 派位（同阿傑同校與否）和 1996 走留。其餘兩難改變的是**記憶與關係**，在後面的分歧點作為台詞、選項文字、戰鬥招式回來。
3. **兩難的代價必須兩邊都寫成記憶卡**，並在下一階段被別人說出口（沿用 `missed` 規則：下一段最多一次，再下次在 1996／1997）。
4. **戰鬥結果是「怎樣」而非「是否」。** 派位戰鬥輸了，你仍然升中，只是派到第三志願；`DAD_TALK` 輸了，結果仍按走／留，但爸爸沒有說出原因。戰鬥寫記憶，不改主軸。
5. **戰鬥招式來自前面的兩難。** 例如陪過嫲嫲 → `FAMILY_TABLE` 有「盛湯」招；問過爸爸為什麼 → `DAD_TALK` 有「問下次幾時」招。這是成長的唯一「數值」出口，玩家看不見數字。
6. **每階段上限**：兩難 ≤ 3、戰鬥 1、有日期的時代插曲 ≤ 2（電視一句或物件）。
7. **戰鬥 spec 審計**：現行審計拒絕第三份戰鬥規格。新增 spec 須自備結算種類（README 規則），審計改為白名單逐階段加入。

## 6. 例子：同一個選擇，撞上不同的人

**例一：1988 中秋「去平台等阿傑」**
- 主角「守約」：阿傑不說多謝，只把燈籠蠟燭分你一半。爸爸一個人去見顧問，回來只說「冇嘢」。
- 主角「會忍」型、平時不出聲：媽媽以為你刻意避開爸爸，罵你「冇心肝」；誤會留到 1996。
- 若新同學是 (a) 私樓：他也在平台，阿傑嫌他「扮嘢」，你要站一邊——同一個選擇多出一個代價。

**例二：1991 幫媽媽填居英權表**
- 撞嫲嫲（根）：她知道後三日不跟你講話，「你哋寫鬼佬名，祖宗點認你？」
- 撞爸爸（務實）：他第一次讚你，「識英文有用」——你被肯定，又覺得對不起嫲嫲。
- 主角「顧家」：你主動去哄嫲嫲，學會兩邊做人；主角「顧自己」：你覺得是大人的事，不理，嫲嫲的湯從此不再留你那碗 ⚠️ 份量要試玩。

**例三：1993 派位填阿傑那間（守約）**
- 撞爸爸：「你為一個朋友賭自己前途？」他整晚坐在門口脫鞋，不說話。
- 撞阿傑家（潮州、要早出來做事）：阿傑反而怒，「我都未必讀得完，你搞咩！」——你守的約，他承擔不起。
- 主角「會問」：你去問阿傑為何怒，知道他爸失業；主角「會忍」：你以為他看不起你，怨到 1996。

**例四：1994 讓房給表哥**
- 撞媽媽（自己人要幫）：她說「你大個咗」。撞嫲嫲：她偷偷塞多一碗湯給你，「你委屈喇」。
- 主角「包容」：表哥 1996 送你一本舊字典，寫上你的名；主角「自保」但被迫讓：你們同房兩年不講話，1997 他第一個打電話問你走不走。

> 嫲嫲：「一家人嚟㗎，讓吓佢啦。」
> 你：「點解次次都係我讓？」
> 嫲嫲：（停一停）「因為你係香港出世嘅。」
