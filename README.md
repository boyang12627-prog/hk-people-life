# 人生・香港　幼年原型源碼

1984–1986 幼年可玩原型，畀評測睇選擇、記憶同畫面點樣扣埋。

可玩版本：[https://hkpeoplelife.grok.me/](https://hkpeoplelife.grok.me/)

呢個 repo 只抽出遊戲本身嘅源碼，未包含成個應用框架同場景圖，所以 clone 完唔可以直接跑。評測請玩上面條連結，讀碼請由下面開始。

## 先睇邊度

| 檔案 | 做咩 |

## v2.2 評測可以留意

- 存檔係 `hklife-p01-v12`，外面包住 `schemaVersion`。舊 v11 會搬過嚟；壞咗嘅 JSON 會當新遊戲，唔會白屏。
- 阿爸返工次數係世界自己計（1985 年尾一次，1986 開年至少兩次）。細路揀玩、應承、定留低，唔會再加次數。同一世界，場面字一樣；唔同嘅係關係、記憶、心情。
- 「呢個唔係第一次」只睇世界次數夠唔夠兩次。
- 同阿媽講：屋企近，個心緊。唔講：少一場鬧，屋企少一句。兩邊都有得到同失去。
- 獨立思考低過 30，仍然可以問「你有個奇怪問題想問」，只係問得弱啲，唔會刪走選項。
- 十年後嗰句先留 1984、1985、1986 各一段最重嘅記憶，再加一段成個童年最重、又未用過嘅。
- 1984 揀「繼續食飯」唔會被 1985 當成聽過將來。記憶先至係事實。
- 1986 出街次數未夠，補一次未夠會再問。只有自己揀留喺屋企，先算放棄邨口。
- 選擇按鈕唔再標夢想／現實。揀完先講你今日偏向邊。
- 幼稚園輸咗唔係 Game Over。
