## V3.4 改了什麼

到目前為止，所有試玩都是模擬的，不是真人。這一版準備真人試玩，並把角色說話分開來處理。

- **兩層用字。** 旁白和動作照舊用簡潔的書面中文，`wording.ts` 對照表強制執行，審計會失敗。對白按角色寫：`SceneLine` 的 dialogue 多了可選的 `register`（`formal`／`narrative`／`colloquial`），預設按說話的人決定（`DEFAULT_REGISTER`）。對白不會失敗，也不會被自動改寫。`dialogueWarnings` 只會列出可能不自然的句子：審計時以 `VOICE WARNING` 列出，並寫進 [docs/VOICE_WARNINGS.md](docs/VOICE_WARNINGS.md)。旁白裡用「」引住的說話也算對白。
- **聲音指引：** [docs/VOICE.md](docs/VOICE.md)，寫了媽媽、爸爸、嫲嫲、阿傑、阿姨、老師各自的語域、節奏、不會說的話和潛台詞。V3.3 在對白裡自動改成書面語的字，比原文自然的都改回去了：今次、拿去用啦、踢波。阿傑、阿姨、嫲嫲說地道廣東話，媽媽和爸爸是書面語法夾香港用詞，老師用書面語。不是每句都寫成口語。
- **爸爸線（一條，由三歲到十五歲）：** 1984「最要緊是一家人安穩」→ 1985 脫鞋脫得很慢 → 1986「下次吧」→ 1986 那天晚上（新）→ 1988 簽測驗卷（新）→ 1996 十一點回家。十五歲那一頁按記憶卡決定說多少：
  - 見過他晚歸，但沒有問過，只說「你沒有問過為什麼」。
  - 問過（1986「下次是幾時」或 1988「為什麼這麼晚」），或見過 1985 加班那個星期日，才會知道他替人留到最後。
  - 「一家人安穩」只在 1984 他真的說過時才回來。
  - 公園那個「下次」，只在你沒有自己走開時，他才「還記得」。
  - 沒有新系統：兩幕新事件用 `EVENT_GATES` 守門，掙不到就跳過。
- **審計：** 每一種爸爸線結果都有測試，也測新一幕不會在掙到之前出現。對白提示有測試，但只報告。
- **真人試玩工具包：** [docs/PLAYTEST_KIT.md](docs/PLAYTEST_KIT.md)，包括同意、觀察員守則、邊玩邊講、觀察表、訪談、結果範本和 V3.4 合格標準。

## V3.3 改了什麼

來源是一次模擬試玩（四個角色、固定種子，不是真人）。修的是「文字和玩家剛做過的事相反」。

- 錯過和回響只看玩家真的做過、看過什麼（記憶卡）。只看世界狀態或下午位置的句子都改了。
- 阿傑：還沒見過他，畫面一律叫「平台上那個抱紅球的孩子」。摺疊的數字也一樣，寫「和那個孩子」。第一次見面那一頁才說他叫阿傑。
- 星期六陪媽媽去了街市，晚上的那頁不再說你整天在家。星期日的街市標籤是「去街市」，旁白寫明媽媽留在家。
- 1986 年尾那一次「下平台」算數：只問一次，算作走到屋邨門口，年尾不再說你沒有上平台。
- 卡片回聲：每頁最多 2 句，P0 也算在內（取代上面「P0 一定出」）。同一主題只出一句，句尾相同的只出一句。
- 年尾和結局的總結看這一年、這幾年的選擇，不再四局同一句。
- 戰鬥：每一步之前都顯示「下一聲／下一題」。跳過和自動只在試玩模式出現：網址加 `?playtest=1`，或 localStorage `hklife-playtest` 設為 `1`；`?playtest=0` 關掉。
- 書面中文：`src/game/wording.ts` 列出廣東話→書面語（紅波→紅球、今次→這次、沖涼→洗澡……）。V3.4 起只在旁白和動作強制執行，對白見下面 V3.4。士多、默書、小息、一毫子、街市、一陣是香港書面用語，保留。
- 審計：`src/game/playtest-audit.test.ts`。每一個 P0 一條測試，P1 每組一條，另加用字掃描。`npm run audit:content` 會一起跑。

## V3.2 改了什麼

- 故事頁和事件卡只有一條 `sequence`：`SceneLine` 是 `narration`、`action`（可帶 `where`）或 `dialogue`（帶 `speaker`）。型別在 `src/game/scene.ts`。
- 1985 的故事頁不再分 `lines` 和 `shots`。以前有 shots 時，lines 和 where/action 會被丟掉；現在每一條都畫出來，順序就是資料的順序。
- 對白由資料寫明誰說，不再用正則從「媽媽：「……」」猜。純字串一律是旁白。`readLine`、`spokenLine` 已移除。
- 審計檢查：每一條 scene line 都有一行畫面；旁白和動作裡不能藏著整句對白；`story.ts` 不再有 lines/shots。
- 圖檔：`imageManifest()` 列出程式真正會用的每一張圖，審計逐張檢查存在。畫面元件不再自己拼 `/art/` 路徑。舊的 `public/art/1985` 場景圖不再是關卡。
- 美術規格只剩一套 Q 版，舊比例和舊句子移到 [docs/ART_BIBLE.md](docs/ART_BIBLE.md) 的〈已廢棄〉。

## V3.1 接上的（仍然有效）

- 同速：孩子先動，不顯示「你先」。快了 5 點才顯示誰先。這條沒有放寬。
- 1988 測驗的壓力速度是 10。機靈 5 的孩子會被試卷搶先。塑膠錶的速度 +1 讓孩子先落筆。這不是「你先」的橫額。
- 原子筆的攻擊只讓每一筆多寫一點卷子。幼稚園不讀攻擊。沒有打人的血量。
- 「看臉色」和「拆開一題」的氣力消耗讀招式目錄，不另寫一份。
- 反應招式不能疊兩次。主動招式有冷卻。「拆開一題」用了之後要隔開一步。
- 塑膠錶仍來自 1984 日常，這是原型例外。原子筆來自支線 `QUEST_SPARE_PEN`。
- 持有和穿上已分開。沒有裝備畫面。

## 玩家看見的

1984、1985、1986，然後 1988 的筆和測驗，再是 1996 一個短場面，然後結局。數值在下一層。選項不標夢想或現實。

1996 會按小時候真正做過的事給一個動作。留著的錶和筆會各多一句。沒有留著，就說記得，但不說還在手上。

## 規格

- 記憶用 `memoryTypeId`（種類）和 `instanceId`（一次）。
- `FLAG_HEARD_ADULT_FUTURE` 只是索引。聽過將來，以 `MEM_NEWS_01` 的 choiceId 為準。
- 卡片回聲用 `selectByPriority`：按 P0、P1、P2 次序取，事件卡每頁最多 2 句，1996 那頁最多 3 句；V3.3 起 P0 也計在內。沒有 P3。
- `designTendency` 只供內容和測試記錄，不改數值。
- 存檔會丟掉未知事件、未知技能、未知 flag、目錄以外的裝備和招式。
- 幼稚園戰鬥 gate：social、safe、curious 三種，各自的 `steady/stabilize+read` 勝率不能低過 20%。沒有叫 tidy 的格子。大考這份規格 `gated: false`，只印數字，不拿幼稚園的門檻當它的關卡。
- 戰鬥決定：一份 engine，多份 spec。幼稚園是 `KINDY_DOOR`，結算是 `kindy`。1988 測驗是 `PRIMARY_EXAM`，結算是 `exam`。引擎按結算種類寫記憶，不再認戰鬥編號。目前只允許這兩種。第三場必須自備結算，不能掉進幼稚園的 `MEM_FIRST_SCHOOL`。審計會拒絕第三份規格。
- 戰鬥編號寫錯時，玩家仍會進幼稚園門口，畫面不會當掉。`npm run audit:content` 會因為這個編號失敗。

## 敘事

1985 先過星期六早上：袋子、爸爸上班、樓梯口看見平台上的紅球。看見不是認識。下午的選擇在這之後才出現。沒有因此加新的人。

阿傑只有一條敘事資料：`ARC_AH_KIT_FRIENDSHIP`。翌日那句「你琴日冇落嚟」，和下一年那句「你去年冇落嚟」（V3.4 起改成阿傑的廣東話，意思不變），都先問這個回收窗口。窗口沒有寫，句子不出。心情數字仍然不改關係。

沒有做雀、石凳上的伯伯、爸爸那份表，也沒有做 1990 年之後。那些是敘事母體，不是這一版的內容。1988 仍然只是測驗切片，不是正式小學。

星期六去街市仍是抽一件，同一條人生固定。第一次開局是走了一圈。星期日如果阿傑不在平台，你又下了樓，會見到另一個沒有名字的孩子。下一年見不回他。十五歲仍然不知道名字。爸爸那個星期六如果留到最後，十五歲才說他是替人留下的。當時只知道鞋子脫得慢。拿過橙的，阿姨記得的是「有個孩子拿了東西」。這幾句是內容，不是新系統。

人類試玩未做。CI 狀態只看該提交的 GitHub Actions 結果，這裡不代寫。

## 1985 的兩個下午

只有 1985。誰在這個地方，只問 resolveWorldAt。星期六結束時 worldTick 結算有規則的人：阿傑、媽媽、嫲嫲、爸爸、阿姨。心情數字和「當天關係變化」只是紀錄，不會再改關係。你去平台、陪媽媽、留在家，星期六、星期日和下一年見面的說法都不一樣。沒有見到的，1986 開頭會再提起，門口那一次選擇也會再出現。兩個下午如果都留在家，爸爸會回來，電視也會再開一次，畫面仍是去年那些很遠的人。兩個下午如果都是自己過，或都在家裡人旁邊，1986 會說出來，不顯示想做或要做的數字。老師不另開一場。阿姨的橙只在袋子裂開、而且街市抽到那一件時才看見。1980 到 1983、1987、1989 沒有做，不是隱藏章節。1986 的兩個下午會決定你見不見到街市、平台和家裡那一次電視。阿傑星期六在平台。星期日去街市，那裡沒有人，媽媽也留在家。自己玩不會把他叫出來。畫畫還是數數、爸爸取消公園、屋邨門口，這三件仍然一定會來。沒有去的，1988 開頭會再提起。1984 的事件順序沒有改。1986 在公園取消之後多了「那天晚上」一幕；1988 筆和測驗的次序沒有改，測驗之後加了簽卷。兩幕都只在掙到才出現（`EVENT_GATES`）。

## 美術
